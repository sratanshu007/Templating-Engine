# Templating Engine (Express + EJS) 🚀

A Node.js Express web application demonstrating dynamic server-side HTML rendering using the **EJS (Embedded JavaScript)** templating engine.

## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js 5
- **Template Engine:** EJS

## 📂 Features
- Dynamic list rendering with condition-based UI (Online/Offline badges)
- User registration form (`/form`) submitting via POST to `/register`
- Reusable EJS partials for modular templates

## 🚀 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   node app.js
   ```

3. Open in browser:
   [http://localhost:3000](http://localhost:3000)
